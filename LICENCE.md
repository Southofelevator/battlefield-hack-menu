## 🧩 About

**Battlefield Companion** is a curated list of Battlefield open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, HUD tweaks
- **Quality-of-Life Helpers** — loadout presets, sensitivity manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review level runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Icon Catalog — browse icons, colors, trails, death effects
- Custom Skin Notes — organize player cosmetics
- Solid Wave Trail — improved wave visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-level
- Jump Buffer Notes — chain complex maneuvers in the editor
